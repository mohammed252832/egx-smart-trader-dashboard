# Changes — 2026-11-28

## What changed

**Look and feel.** Light theme taken from the reference design: primary green `#006844`, page `#f3faf7`,
cards `#fcfffe`, borders `#cfdfdb`, text `#151c1f`. IBM Plex Sans Arabic. Tokens live in `app/globals.css`.
The floating menu became a sticky header; the menu keeps "آخر تحديث للسوق" and "الرسوم الشهرية" and adds "حسابي".

**Accounts.** Sign in, sign up, a "pending approval" page and an account page (display name, alert preferences,
watchlist). The shared-password login is gone. New accounts start as `pending`; an admin approves them:

```sql
update public.profiles set status = 'approved' where email = 'person@example.com';
```

`kigobigo11@gmail.com` is in `private.admin_emails` and is approved and flagged admin on sign-up. Edit that table to change it.
Existing `shared@egx-smart-trader.invalid` still works at the database level but has no login form any more.

**Home page.** Market state chart (bullish / bearish / mixed) · top 10 stocks · liquid stocks likely to rise ·
daily market liquidity + leaders. Backed by four views (see `20261128130000_market_state_liquidity_views.sql`).

## Supabase settings to check (not controllable from SQL)

1. **Authentication → Providers → Email:** decide whether "Confirm email" is on.
2. **Authentication → Email Templates → Confirm signup:** use
   `{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=signup`
   (the default link also works; `/auth/confirm` now accepts `?code=` too).
3. **Authentication → URL Configuration:** Site URL = the production URL, and add `<site>/auth/confirm` to Redirect URLs.
4. **Vercel env:** `NEXT_PUBLIC_SITE_URL` must be exactly `https://egx-smart-trader.vercel.app`.
5. Optional: enable leaked-password protection (Authentication → Passwords).

## Known limits

- The model predicts 3 sessions. A "one week" horizon needs an engine change (`EGX_HORIZON_DAYS`, a second model).
- After the sample-data cleanup, 34 symbols have gaps in `aggregated` bars until the analysis workflow runs again.
- The market-state index is only as complete as `market_daily_bars`; the page warns when fewer than 60 of 100 stocks have data.
- This code was syntax-checked but not built or run (no network in the authoring environment). Run `npm install && npm run build` before merging.
- `.github/workflows/provision-accounts.yml` and the `docs/` pages still describe the shared password; retire them when convenient.
